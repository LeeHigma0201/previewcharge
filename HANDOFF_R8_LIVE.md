## KEY LEARNINGS FOR NEXT SESSION

1. **TwinSpires bet syntax (use exactly):**
   - `TR` = Trifecta
   - `TR BOX` = Trifecta Box
   - `TR KEY` = Trifecta Key (anchor in slot 1, others spread)
   - `TR KEY BOX` = Trifecta Key Box (anchor across slots, others boxed)
   - `EX` = Exacta
   - `SUPER` = Superfecta
   - `HI5` = Super High 5
   - Format examples: `TR 3,2/3,2/9,8,5 @ $0.50` (part-wheel) · `TR BOX 2,3,8,9 @ $0.50` · `TR KEY 3 / 5,8,9` etc.

2. **Verified base unit minimums:**
   - $0.50 base: TR (all variants), Pick-N
   - $1 base: EX (some), SUPER (default), HI5 BOX
   - $0.10 base: HI5 part-wheel (NOT BOX — verify before submitting!)

3. **DO NOT** suggest a `$0.10 HI5 BOX of 5 horses` thinking it's $12. TS BOX wagers default to $1 base = $120. **Use part-wheels for cheap Hi-5 coverage.**

4. **Algo top 4 = strong signal.** When algo confidence is HIGH and edge tier is FULL or PARTIAL, **trust the strict top 4 ranking**. AI adversarial reviews should EXPAND spread, not REPLACE algo ranks.

5. **R5 + R6 + R7 confirmed: algo nails 3-4 of top 5 finishers consistently.** The right structure is `$0.50 TR BOX of algo top 4` ($12, 24 combos) when confidence is HIGH/MEDIUM.

6. **Derby is the priority. Discipline > complexity.**
